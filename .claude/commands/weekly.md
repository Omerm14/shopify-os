Arguments: $ARGUMENTS

1. **analyst**: 7-day and 28-day trends for every exit-gate metric of the current stage; close experiments past their window.
2. **finance**: weekly P&L, breakeven CPA/ROAS refresh, cash position.
3. **auditor**: update `state/autonomy.yaml` counters from Linear; per agent recommend keep / promote / demote with evidence.
4. Each active agent: one paragraph — what it learned (append to `memory/learnings.md`), what it will test next.
5. **orchestrator**: write `logs/weekly/<YYYY-Www>.md` from `templates/weekly.md`, including max 3 decisions needed from the Owner. Post to Slack.
6. If `--quarterly`: scout and finance add a portfolio section — new products, markets, channels; recheck Shopify sales-channel and AI-shopping settings.
7. Commit `[orchestrator] weekly <YYYY-Www>`.
