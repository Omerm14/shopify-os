# Memory

Append-only. Never edit or delete past entries; correct by adding a new one that references the old.

| File | What goes in | Format |
|------|-------------|--------|
| `learnings.md` | One-line lessons any agent can act on | `- YYYY-MM-DD [agent] <lesson> (EXP-id) #tags` |
| `decisions.md` | Owner decisions and why, including edits/rejections of proposals | `## DEC-YYYYMMDD-n — title` then context, options, decision, reason |
| `experiments/` | One file per experiment | `templates/experiment.md` |

**Tags** keep lessons findable: `#creative #hook #angle #offer #price #pdp #email #sms #care #supplier #shipping #ads-meta #ads-google #ads-tiktok #incident #owner-preference`.

**Promotion of lessons:** a lesson confirmed in 3 separate experiments becomes a proposed rule (PR to `playbook/` or a role file).

No customer personal data here: order IDs and aggregates only.
